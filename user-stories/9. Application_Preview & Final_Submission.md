Module 9 – Application Preview & Final Submission

1. Purpose
The Application Preview & Final Submission module is the final stage of the SAHAYOG application workflow. It enables applicants to review all entered information, validate uploaded documents, provide declaration and consent, and submit the application successfully.
This module ensures that only complete, validated, and confirmed applications are submitted to the system for further processing.

2. Module Overview
After successfully uploading all mandatory documents, the applicant is redirected to the Application Preview & Final Submission page.
The module allows users to:
Review all application details. 
Verify personal information. 
Verify scheme details. 
Verify uploaded documents. 
Edit previous sections if corrections are required. 
Accept declaration and terms. 
Submit the application. 
Generate Application Number. 
View acknowledgement. 
Download or print acknowledgement receipt. 

3. Business Objective
The Application Preview & Final Submission module aims to:
Provide a final review before submission. 
Prevent submission of incomplete applications. 
Capture applicant consent and declaration. 
Generate a unique application reference number. 
Produce an acknowledgement receipt for future tracking. 
Lock submitted applications against unauthorized modification.

Upon successful submission:
Application status changes to Submitted. 
Unique Application Number is generated. 
Submission timestamp is recorded. 
Audit log is updated. 
Acknowledgement receipt is generated.

If submission fails:
Application remains in Draft status. 
User remains on Preview page. 
Appropriate error message is displayed. 
Previously entered data remains unchanged.
