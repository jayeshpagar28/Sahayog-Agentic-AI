Module 8 – Document Upload

1. Purpose
The Document Upload module enables applicants to upload all mandatory and optional supporting documents required for scheme eligibility and application processing.
This module ensures that uploaded documents meet predefined validation criteria (such as file type and size), are securely stored, and are associated with the correct application.
Only applicants who have successfully completed previous verification stages can proceed to document upload.

2. Module Overview
After successful Aadhaar Verification, the applicant is redirected to the Document Upload module.
The module allows users to:
View the list of required documents. 
Upload mandatory and optional documents. 
Preview uploaded documents. 
Download uploaded documents. 
Replace existing documents. 
Delete uploaded documents (before final submission). 
Validate upload status. 
Continue to the Application Preview page. 

3. Business Objective
The Document Upload module aims to:
Collect all supporting documents required for application processing. 
Validate document format and size before upload. 
Prevent submission of incomplete applications. 
Ensure uploaded files are securely stored. 
Improve document quality and reduce manual verification effort.
