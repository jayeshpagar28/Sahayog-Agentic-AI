SAHAYOG Web Portal
Module 2 – Homepage

1. Module Overview
The Homepage is the default landing page displayed immediately after successful user authentication. It acts as the central dashboard of the SAHAYOG Portal by providing users with quick access to their profile, notifications, alerts, application progress, and navigation to different portal services.
The Homepage should load all configured widgets, cards, alerts, branding elements, and navigation menus based on the authenticated user's permissions. It serves as the primary entry point for all subsequent user activities within the portal.
Since every authenticated user interacts with the Homepage before accessing any business module, this module should be considered a reusable entry point and included in all Smoke and Regression automation suites.

2. Business Objective
The Homepage module is designed to:
Provide a centralized dashboard immediately after login. 
Display important alerts and announcements. 
Display the current date. 
Display user-specific notifications. 
Provide quick access to profile-related actions. 
Allow users to navigate to all authorized modules. 
Display branding and application information. 
Improve user experience through a responsive and intuitive interface. 

3. User Story
Title: Homepage Dashboard
As a registered SAHAYOG Portal user,
I want to view the Homepage immediately after logging into the application,
So that I can view important information, notifications, alerts, and quickly navigate to available services.
