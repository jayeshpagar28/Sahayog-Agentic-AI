Module 3 – Unposted Applications

1. Purpose
The Unposted Applications module acts as the primary dashboard for applicants to view and manage all applications that have been created but are still under processing or pending completion. It provides search, filtering, application tracking, cancellation, and quick access to create new applications.
This module helps applicants monitor application progress and perform permitted actions without navigating through multiple screens.

2. Module Overview
After successful login, users can access the Unposted Applications page to:
View all applications in a grid. 
View application status summary cards. 
Search applications using Mobile Number or Application ID. 
Filter applications using Product, Scheme, and Date. 
Track application progress. 
Cancel eligible applications. 
View complete application details. 
Create a new application. 
Monitor application counts by status. 

3. Business Objective
The Unposted Applications module aims to:
Provide a centralized view of all applications. 
Allow applicants to quickly locate applications. 
Display real-time application status counts. 
Enable application tracking. 
Allow cancellation based on business rules. 
Support efficient application management through filters and search. 

4. User Stories
User Story 1 – View Application Dashboard
As an applicant,
I want to view all my applications on a single page,
So that I can easily monitor their current status.

User Story 2 – Search Application
As an applicant,
I want to search applications using my Mobile Number or Application ID,
So that I can quickly locate a specific application.

User Story 3 – Filter Applications
As an applicant,
I want to filter applications by Product, Scheme, and Date,
So that I can narrow down the application list.

User Story 4 – View Application Details
As an applicant,
I want to open an application's details,
So that I can verify all submitted information.

User Story 5 – Track Application
As an applicant,
I want to view the complete application timeline,
So that I know the current processing stage.

User Story 6 – Cancel Application
As an applicant,
I want to cancel an eligible application,
So that I can discontinue processing when required.

User Story 7 – Create New Application
As an applicant,
I want to start a new application from this page,
So that I can apply for another scheme without returning to the homepage.

User Story 8 – View Status Summary
As an applicant,
I want to see application counts grouped by status,
So that I can understand the overall progress of my applications.
