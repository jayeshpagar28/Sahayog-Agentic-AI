## Notes on Scope
- TC-LOGIN-011 through -013 and -017 hit the **real remote environment** (`14.142.238.28`) with the provided valid credential — each run creates a real session against a live server, not a sandbox.
- Scenario 15 (Forgot Password full flow, incl. email delivery) is scoped to "link opens the flow" only; verifying actual email receipt is out of scope for UI automation.
- Logout (traceability TC_05) is out of scope for this run — the story's Post/Preconditions describe it, but no logout control was located from the login-only entry point during recon; would need dashboard-module scope to automate.
